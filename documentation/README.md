# Documentation

Everything about JobPortal that isn't code lives here: how the code works, our school project documents, and design ideas.
If you're not sure where something goes, put it here and mention it in the group chat.

| Folder or file | What goes in it |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | how the code works: the packages, a request from start to finish, the profile, a search run |
| [school/](school/) | CMSC 495 7304 work: the proposal, reports, presentations, meeting notes and the final submission |
| [design/logos/](design/logos/) | logo ideas and sketches |
| [design/colors/](design/colors/) | color scheme ideas |
| [design/fonts/](design/fonts/) | font ideas and font files we might use |

The README and CONTRIBUTING guide stay at the top of the repo, because GitHub shows them from there.

## A few rules

- **Name files so they sort well**, with the date first: `2026-11-03 status report.docx`, `2026-11-10 logo sketches.png`.
- **Keep files under 50 MB.** GitHub refuses files over 100 MB. Put big videos somewhere else (like Google Drive) and add a
  link to them in a Markdown file here.
- **No personal data.** Team names and roles are fine. Real resumes, grades, student IDs and anyone's private contact
  details are not.
- **PDF and Word files are allowed in this folder.** The rest of the repo blocks them, so a real resume can't get committed
  by accident.
